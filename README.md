# -----Real-Time Global DNS Attack Visualization System-----

## ----Project Overview----
This project visualizes simulated DNS/cyberattack traffic between countries using Python and a 3D globe model.

## ----Technologies Used----
- Python
- Plotly
- Blender
- Data Visualization

## ----Features----
- 3D Earth globe model
- Simulated DNS attack paths
- Country-to-country attack visualization
- Interactive globe visualization
